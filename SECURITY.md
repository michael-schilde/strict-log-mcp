# Security policy

Please report vulnerabilities privately through GitHub's [private vulnerability reporting](https://github.com/michael-schilde/strict-log-mcp/security/advisories/new) instead of opening a public issue. I will reply within a week.

The server writes files on your machine on behalf of an AI agent. Path containment (the root folder and the per-log file name) is the main security boundary, so reports about ways to write outside the configured root are especially welcome.
